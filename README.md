# VeltrixOS (now in dev) 🐧

An Operating System created for users who value system efficiency and speed, powered by a custom package manager (VPM) that builds everything from source.

## 🚀 Key Features
* **Zero Bloat:** Engineered for raw performance and maximum efficiency.
* **VPM (VeltrixOS Package Manager):** A custom, independent package manager built from scratch in pure C++.
* **Built for Power Users:** Complete control over your compilation and system environment.
