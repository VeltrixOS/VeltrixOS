# Contributing to VeltrixOS 🚀

Thank you for your interest in VeltrixOS! We want to keep the system fast, modern, and light. Here are a few guidelines:

## ⚙️ Coding Rules
* **Language:** VPM is built using pure C++. 
* **No Bloat:** Keep code efficient, fast, and optimized.
* **Architecture:** Remember our goal of keeping package compilation fully independent and sandboxed from the host system.

## 🐛 How to contribute
1. Look at open **Issues** or create a new one to discuss your ideas.
2. Fork the repository and create your branch.
3. Make sure your code is clean and tested.
4. Open a **Pull Request** explaining your changes.
