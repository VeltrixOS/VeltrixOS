# Security Policy

## Supported versions

VeltrixOS is in early development. Only the latest release and `main` receive security fixes.

## Reporting a vulnerability

Do not open a public issue for a vulnerability.

Use GitHub private reporting: **Security** tab → **Report a vulnerability**.
Include:
- affected component (kernel config, VPM, package recipe, ISO scripts),
- VeltrixOS and VPM version,
- steps to reproduce and impact.

You get a first reply within 7 days. Fixes are published after a patch is available.
